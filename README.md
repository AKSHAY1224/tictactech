# ⚡ TicTacTech

`// three in a row, zero dependencies`

A tech-themed Tic-Tac-Toe that runs as a **100% static site** — no server, no build step, no frameworks, no external requests. Open the link on a laptop or a phone and play. Install it and it keeps working offline.

> **Play now:** <https://akshay1224.github.io/tictactech/>
>
> **Status:** v1.1.0 · plain HTML + CSS + JavaScript · works on GitHub Pages out of the box

## Features

- 🤖 **Vs BOT.exe** — three difficulties. `hard` is perfect play (minimax with alpha-beta pruning) and is proven unbeatable by an exhaustive test.
- 👥 **Local 2P** — pass-and-play on one device.
- 🎮 **Four variants** — Classic, Infinity (oldest mark vanishes), Blitz (beat the clock), Misère (three in a row *loses*).
- 🌗 **Dark / Light / System theme**, accent themes (Neon, Synthwave, and a hidden Matrix mode).
- 🧩 **Symbol packs** — Code `</>` `{ }`, Binary `1` `0`, Classic `X` `O`, Circuit chip / bolt — all drawn as animated SVG.
- ✨ **Smooth** — 60 fps stroke-drawn marks, animated win line, confetti, circuit-board background, custom desktop cursor, button ripples. Everything respects *reduce motion*.
- 🔊 **Sound & haptics** — synthesized with the Web Audio API (no audio files), vibration on phones, both switchable.
- 🏆 **Stats & badges** — win rates, streaks, time played, 13 tech-flavoured achievements.
- ⌨️ **Keyboard playable** — number keys, arrows, shortcuts, screen-reader announcements.
- 📱 **Installable PWA** — offline after the first visit, update toast when a new version is deployed.
- 🕹️ An easter egg. Try the Konami code (or tap the logo seven times on a phone).

## Play modes and variants

| Mode | What it is |
|---|---|
| Vs BOT.exe | You vs the computer. `easy` is random-ish, `medium` blocks and wins but can be forked, `hard` cannot be beaten. |
| Local 2P | Two people, one device, alternate turns. The loser starts the next round. |

| Variant | Rule |
|---|---|
| Classic | Three in a row wins. Full board is a draw. |
| Infinity | Each player keeps at most 3 marks. Placing a 4th removes your oldest (it fades before it goes). No draws. |
| Blitz | Classic with a 3 / 5 / 10-second timer per move. Time out and a random cell is auto-committed. |
| Misère | Making three in a row **loses**. |

## Controls

| Key | Action |
|---|---|
| `1`–`9` | place a mark (reading order) |
| `← ↑ ↓ →` | move focus on the board, `Enter` / `Space` to place |
| `R` | reboot the game |
| `U` | undo (not in Blitz) |
| `H` | hint (vs easy / medium bot) |
| `N` | new session after a game ends |
| `T` | toggle theme |
| `M` | mute / unmute |
| `C` | toggle the console panel |
| `Esc` | close |
| `?` | shortcuts help |

Touch: tap a cell to play. Everything has ≥ 44 px touch targets.

## Tech stack

- **HTML5**, **modern CSS** (custom properties, grid, `clamp()`, `dvh`, `color-mix()`), **ES2020+ JavaScript modules**.
- Zero runtime dependencies. No bundler, no transpiler, no CDN, no fonts fetched from the network.
- Pure game engine (`js/engine/`) with no DOM access, tested with Node's built-in test runner.
- Service worker + web app manifest for offline use and installation.
- Sounds are synthesized in the browser; icons are generated by a dependency-free Node script.

## Run locally

Modules and the service worker need an HTTP server (opening `index.html` directly from the file system will not work).

```bash
# any of these, from the project folder
python -m http.server 8080
npx serve .
```

Then open <http://localhost:8080/>.

Add `?debug=1` to the URL to expose a `window.__TTT` handle in the DevTools console (state, actions, engine functions).

## Run the tests

Requires Node.js 18+ (nothing to install):

```bash
node --test
```

The suite covers the board and variant rules, the storage wrapper, the share helpers, and the AI — including an **exhaustive proof** that `hard` never loses in Classic and Misère whether it moves first or second.

## Deploy to GitHub Pages

1. Create a **public** repository on GitHub (for example `tictactech`).
2. Upload **all** files and folders from this project, including the hidden `.nojekyll` file (it tells GitHub not to run Jekyll, which would otherwise ignore some files).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose branch **`main`** and folder **`/ (root)`**, then click **Save**.
5. Wait 1–3 minutes. The page appears at:

   ```
   https://<your-username>.github.io/<repository-name>/
   ```

6. Share that link. It opens on any laptop or phone, and can be installed from the browser menu ("Install app" / "Add to Home Screen").

### Publishing an update

Every time you change files after the first deploy, bump the cache version so installed copies pick up the new build:

- open `sw.js` and change `const CACHE_VERSION = 'ttt-v1.1.0';` to a new value (for example `ttt-v1.1.1`),
- optionally bump `APP_VERSION` in `js/main.js` (shown in the footer),
- push. Open tabs will show an **update available — reload** toast.

### Troubleshooting

| Symptom | Fix |
|---|---|
| Blank page on GitHub Pages | Make sure `.nojekyll` was uploaded and that the site is served from the repository root. All paths in this project are relative (`./…`), so sub-paths work. |
| Old version keeps showing | Bump `CACHE_VERSION` in `sw.js` and push again; or hard-reload (Ctrl/Cmd + Shift + R). |
| "Install" button missing | Install requires HTTPS (GitHub Pages provides it) and a valid manifest; it only appears once the browser considers the app installable. |
| No sound | Sound starts after your first tap or click (browser autoplay rules). Check the speaker button in the toolbar and the device volume. |
